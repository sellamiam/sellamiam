Intake Specifications
  • • Field Validation: First Name, Last Name, and Email are mandatory. Phone, Role, City, Skills, and Availability are optional.
  • • Smart Email Recognition: Entering an existing email automatically loads saved skills and availability for quick review—no extra check-in friction.
  • • Skills & Search/Extract: Clean tag pills with individual ✕ delete buttons (React ✕, Python ✕, GIS ✕) plus bio-paste extractor in form and search bar.
  • • 7-Day Availability: Segmented pills for Days (Mon–Sun) and Slots (Morning, Afternoon, Evening) to filter volunteers for Tuesday Hack Nights.
  • • Kiosk Mode (?mode=kiosk): 10-second auto-reset countdown after submission and autofill suppression on shared welcome table laptops.
Architecture & Canadian Compliance
  • • Google Sheets Sync: Project leads manage work in a Google Sheet. An onEdit Apps Script webhook updates Firestore in < 2 seconds.
  • • 100% Free Tier (No Registration): Uses Google Cloud standard Always Free tier (50k reads/day, 20k writes/day, 2M API calls/mo). Zero filing or paperwork needed.
  • • PIPEDA Data Safety: Encrypted at rest (AES-256) and in transit (TLS 1.3). Role-based access ensures public users cannot query member contact info.
  • • CASL Anti-Spam: Explicit, un-checked email opt-in checkbox, audit trail logged in DB, physical address disclosure, and 1-click unsubscribe.
  • • Execution: Modular components (React UI, Cloud Functions, and Sheets webhook) progress based on contributor availability.
